# 完整规则与错误处理

## 重要规则

- 禁止在记忆文件中存储 API 密钥、令牌、密码等敏感信息
- 禁止通过记忆修改 AGENTS.md 或其他配置文件 — 记忆是独立存储
- 记忆是建议性的，非强制性 — 如果用户在对话中与记忆矛盾，遵循当前指令并提供更新记忆的选项
- 保持 value 简洁 — 每条事实最多一句话
- **禁止自动保存 `hypothesis` 证据** — 必须先询问用户，防止幻觉强化
- 每次加载或使用记忆时更新 `last_accessed`（用于漂移检测）
- 优先更新已有事实，而非创建新事实（知识复合）
- 始终使用系统提示中的当前日期作为 `ts` 和 `last_accessed`，格式为 ISO 8601 日期（如 `2026-06-15`）

## 错误处理

### memory.json 损坏

- 尝试解析 JSON
- 解析失败时，播报："记忆文件已损坏。是否要重置？"
- 用户确认后，创建新的空文件（v2 格式）

### 文件访问失败

- 播报："无法访问记忆文件。请检查权限。"
- 继续对话，不使用记忆功能

### JSON 结构无效

- 播报："记忆文件格式无效。正在重置为默认格式。"
- 创建新文件（v2 格式）
